# 🐍 Python Interview Questions (50+ Solved)

A collection of commonly asked Python interview questions, solved in Jupyter Notebooks. Each question is worked through in stages: a simple first approach, then a cleaner, production-style function with type hints, docstrings, and input validation.

## 📂 Files

| File | Questions | Topics |
|------|-----------|--------|
| `Interview_Que.ipynb` | Q1 - Q37 | Strings, numbers, lists, recursion, sorting, searching, stack, file handling |
| `38-51.ipynb` | Q38 - Q51 | Dictionaries, queue, math, bit tricks, in-place algorithms |

## 🧠 Topics Covered

- **Strings:** reverse string, palindrome, anagram, count vowels, character frequency, remove whitespace, longest word, first non-repeating character, remove nth occurrence, digits-only check
- **Numbers & Math:** prime numbers (single and range), factorial (loop and recursion), Fibonacci, leap year, power, GCD (Euclidean and recursive), LCM, sum of digits, reverse an integer, Armstrong number, check power of 2, sum of N natural numbers
- **Conversions:** decimal to binary, binary to decimal
- **Lists:** largest and second largest, remove duplicates, intersection, common elements in 3 lists, flatten nested list, find pairs with a given sum, find missing number, median, reverse array in place
- **Sorting & Searching:** bubble sort, merge two sorted lists, check if list is sorted, binary search
- **Data Structures:** Stack (LIFO) and Queue (FIFO) using lists
- **Dictionaries:** list of tuples to dict, sort dict by key, nested dictionary operations
- **File Handling:** word frequency count from a text file
- **Concepts:** recursion, two-pointer technique, bitwise operations, tuple unpacking

## ✨ Approach

For each problem:
1. **Basic solution:** straightforward logic to build understanding
2. **Improved solution:** a reusable function with type hints and docstrings
3. **Edge cases:** `TypeError` / `ValueError` handling for invalid inputs

## 🚀 How to Run

```bash
git clone https://github.com/<your-username>/<repo-name>.git
cd <repo-name>
pip install jupyter
jupyter notebook
```

Then open either notebook and run the cells.

> **Note:** Question 29 (word frequency) reads a local text file. Update the file path to point to your own `.txt` file before running.
